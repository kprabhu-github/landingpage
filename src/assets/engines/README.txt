Put the official AI engine logos in this folder, named exactly:

  chatgpt.svg      (OpenAI / ChatGPT logo)
  gemini.svg       (Google Gemini logo)
  perplexity.svg   (Perplexity logo)
  google-ai.svg    (Google "G" logo, for AI Overviews)

.png or .webp also work. Square logos with transparent backgrounds look best.
Download them from each company's official brand / press page and follow
their usage guidelines. Then run: npm run build:single
